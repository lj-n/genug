# PROTOTYPE — Checkpoint wording, EN/DE (question 4)

Throwaway branch `prototype/checkpoint-page`. The final copy for every string
the prototype hard-codes. Terms follow `GLOSSARY.md`: **Checkpoint** in both
languages (never "Kontrollpunkt"), **Adjustment / Ausgleichsbuchung**,
**Checkpoint suggested / Checkpoint empfohlen** (never "due"/"fällig"),
validated = **bestätigt**, sealed = **abgestempelt** (matches the stamp icon; picked over festgeschrieben, versiegelt, abgeschlossen, gesperrt, fixiert), transfer = **Umbuchung**, du-form as in
`messages/de.json`. `{name}` = account name, `{date}` = formatted date.

## Account page: entry point

| Where                        | EN                         | DE                            |
| ---------------------------- | -------------------------- | ----------------------------- |
| Stamp button label + tooltip | Checkpoint                 | Checkpoint                    |
| Tooltip when suggested       | Checkpoint suggested       | Checkpoint empfohlen          |
| Line under the name          | Last checkpoint {relative} | Letzter Checkpoint {relative} |
| Line before the first one    | No checkpoint yet          | Noch kein Checkpoint          |

`{relative}` comes from `Intl.RelativeTimeFormat` ("last month" / "letzten Monat").
