# i18n

Paraglide JS (`@inlang/paraglide-js`). Two locales: `de` (base) and `en`.

## Files

| Path | Purpose |
|---|---|
| `messages/de.json` | German translations (base locale) |
| `messages/en.json` | English translations |
| `src/lib/paraglide/` | Auto-generated runtime (gitignored) |
| `project.inlang/` | Paraglide config |

## Message format

Flat key-value JSON. Parameters use `{variable}` syntax:

```json
{
  "login_error_username_minlength": "Username must be at least {length} characters",
  "budget_title": "Budget"
}
```

## Usage

```typescript
import { m } from '$lib/paraglide/messages';

m.login_error_username_minlength({ length: 3 })
m.budget_title()
```

The `m` namespace is generated — each message key becomes a typed function. Import from `$lib/paraglide/messages` everywhere (client and server).

## Locale detection

Strategy: cookie first, then base locale (`de`). Handled by `paraglideMiddleware` in `src/hooks.server.ts` (the `handleParaglide` handle).

## HTML integration

`src/app.html` contains `%paraglide.lang%` and `%paraglide.dir%` tokens that the middleware replaces with the current locale and text direction per request.

## Adding a new message

1. Add the key to `messages/de.json` (base locale).
2. Add the same key to `messages/en.json`.
3. The generated `src/lib/paraglide/` files update automatically on next dev server start or build.
